01) Explain what is serverless architecture?

A serverless architecture is a way to build and run applications and services without managing infrastructure. The term “serverless” indicates that there are no servers, but there are servers and hardware infrastructure. But the cloud service provider is responsible for configuring, maintaining and managing servers instead of you. This means developers are able to concentrate on coding and not hardware tasks.

One common use case of serverless architecture is the development of chatbots and virtual assistants. Here serverless functions can respond to user requests through messaging platforms or voice interfaces and automatically balance the requests according to the number of users. Serverless architecture is also widely used for real-time data processing, as serverless functions can process streaming data immediately for purposes such as analytics, system monitoring, and generating alerts without requiring organizations to manage dedicated processing servers.

Even though the serverless architecture has its benefits, it also has its own limitations. One of the main issue happens when a cloud service provider has to run a function that has not been used for long time. This situation may lead to a small delay in the execution process. Another problem is vendor lock-in, as the applications may become strongly connected to services and tools provided by a specific cloud provider. Also, monitoring and debugging many different functions that build the application may be more complicated than managing the regular application.
